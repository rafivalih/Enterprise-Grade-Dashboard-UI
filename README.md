# 🚀 Enterprise-Grade Dashboard UI

A modern and responsive dashboard UI built using React and Tailwind CSS.  
This project demonstrates scalable frontend architecture, reusable components, authentication flow, protected routes, theme management, and interactive dashboard layouts.

---

## ✨ Features

- 🔐 Authentication System
- 🛡️ Protected Routes
- 🌗 Dark / Light Theme Toggle
- 📊 Dashboard Analytics Cards
- 👥 Dynamic User Table
- ⚡ Reusable Components
- 📱 Fully Responsive Design
- ⏳ Loader & State Handling
- 🎨 Modern UI with Tailwind CSS

---

## 🛠️ Tech Stack

- React.js
- Tailwind CSS
- JavaScript
- Context API
- React Router DOM

## 🚀 Installation & Setup

Clone the repository:

```bash
git clone https://github.com/rafivalih/Enterprise-Grade-Dashboard-UI.git
```

Move into the project directory:

```bash
cd Enterprise-Grade-Dashboard-UI
```

Install dependencies:

```bash
npm install
```

Run the project:

```bash
npm start
```
